chomsky.woff2
=============

Font:    Chomsky
Weight:  400 (Regular)
Format:  WOFF2
License: SIL Open Font License, Version 1.1
Source:  https://github.com/ctrlcctrlv/chomsky
         https://cdn.jsdelivr.net/gh/ctrlcctrlv/chomsky@master/dist/Chomsky.woff2

Used by this site for the latin <h1> headline only (see --headline in
scripts/daily/render.mjs) — a NYT-masthead-style blackletter. CJK headline
text falls through to the system 宋体 (Songti/SimSun/Noto Serif CJK); no CJK
webfont is loaded. The full OFL license text ships with the upstream Chomsky
project: https://github.com/ctrlcctrlv/chomsky
