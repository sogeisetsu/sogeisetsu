Work in own repositories

The window's largest effort went into sogeisetsu/asset-inventory, which moved through a dense chain of releases from v1.3.0 to v1.15.0. Early versions made the skill English-first with a paired Chinese doc set, then added seven fixed-string languages (ko/ru/ar/es on top of en/zh/ja), rendered bilingual sample pages, and a Material docs site. Later work fixed real defects: MCP enumeration silently dropped servers, update.ps1 mishandled nested directories, and the language claim in SKILL.md could not be backed by the glossary; each fix came with a new checker rule so the gap could not reopen. The last releases added a version-consistency check, PR-triggered docs checks, a 🛑broken state marker in seven locales, security guards for scanned content, a registry-first host-command scan, and a skills.sh one-line install.

sogeisetsu/meld-deepresearch produced four releases. v0.2.0 wrote down the rule for unreachable sources, v0.3.0 split the skill into three cooperating skills (core research, spreadsheet analysis, and a third capability skill) with a cleaner reading copy and hard delivery gates, and v0.4.0 wrapped the six gate scripts behind a single meld.py CLI with prepare, render and review subcommands. The repository also gained a bilingual GitHub Pages landing page with light and dark themes, a Chinese README with a language switch, and validation scripts plus CI.

sogeisetsu/opencode-go-model-picker shipped v1.0.0 through v1.4.0. The skill fetches the live OpenCode Go plan and recommends models per custom agent under budget, balanced and quality modes; later versions added a three-part output body with a data appendix, two discovery scripts (discover-agents.mjs, snapshot-summary.mjs), and shared helpers for BOM-tolerant JSON and proxy-aware re-runs.

Smaller own work covered opencode-agent-sandbox, where a knowledge/ base was started and corrected for OpenCode V2 distribution, auth and Windows path pitfalls, and opencode-skill-management, where a skill_management plugin implementing list, inspect, disable and enable was built and its feasibility spec revised. myBlog received three OpenChamber screenshot samples.

Upstream reporting

In anomalyco/opencode twelve items were filed on MiMo-V2.6-Flash vision and Go endpoint image rejections, model listing after auth removal, and missing Windows CLI entry points. Smaller reports went to oh-my-opencode-slim, OfficeCLI, SenseNova-Skills, SenseNova-Skills-DeepResearch and vercel-labs/skills. PRs were opened in antongulin/opencode-skill-creator for CRLF frontmatter handling, review-server disposal, platform-specific browser opening and eval robustness, and one listing PR was opened against VoltAgent/awesome-agent-skills.

Daily dashboard
