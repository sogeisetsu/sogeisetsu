Skill tooling and releases

Most of the work went into a family of OpenCode skills. opencode-skill-management grew from a first release candidate to a stable 1.0.0 and then 1.1.0 and 1.2.0, adding a skill_management plugin with list, inspect, disable and enable actions that write a single permission rule instead of touching skill files. Later versions moved all four actions to a single JSON object with a declared output schema, and fixed list reporting false divergence across hidden internal agents.

meld-deepresearch shipped 0.2.0, 0.3.0 and 0.4.0: explicit handling for blocked sources, validator hints on failure, a split into cooperating skills, and a thin meld.py CLI wrapping the gates. opencode-go-model-picker reached 1.3.0, 1.4.0, 2.0.0 and 3.0.0, adding agent-discovery and snapshot-summary scripts, shared JSON and proxy helpers, priced quota accounting, and a large text reduction.

New projects and blog

sopen-translate was started from scratch as an MV3 extension with bilingual page rendering, chunk splitting, a circuit breaker, a provider protocol layer and glossary pipeline, then narrowed to page translation only with JSDoc type checking and smoke tests. opencode-agent-sandbox was initialized and filled with an archived knowledge base covering OpenCode V2 distribution, authentication and Windows path issues. asset-inventory corrected skill invocation facts across rules, samples and guides and released v1.15.4 and v1.15.5. myBlog received four OpenChamber capture screenshots.
