opencode-go-model-picker reached 1.4.0, 2.0.0, 3.0.0 and 3.0.1. The releases added shared JSON and proxy helpers, fuller agent discovery with skipped built-ins reported, priced accounting with quota math, and a large documentation simplification that cut the model-facing text by roughly an order of magnitude. Script fixes covered atomic snapshot writes, version-badge drift and calibration dates.

Elsewhere, sopen-translate was initialized as an MV3 extension with page translation, bilingual rendering, chunk splitting, a circuit breaker, a provider protocol layer and glossary pipeline, then refactored to drop selection translation. pixel-logo-toolkit shipped 0.2.0 and 0.3.0 with automatic text wrapping, overflow protection, a bilingual CLI and an English-first README. dsh-ecosystem-report got mobile viewport fixes, a single-button theme switcher and visual refinements; asset-inventory released 1.15.4 and 1.15.5 correcting skill invocation facts; myBlog added OpenChamber capture samples.

Upstream, issue activity concentrated on openchamber/openchamber and anomalyco/opencode, with bug reports on MCP settings, session retention hints, quote-card navigation, file-view commenting, context-panel breakdowns and MiMo image handling, plus one PowerToys Shortcut Guide report. No pull requests or reviews were recorded, and no days in the window are missing data.
