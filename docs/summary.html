Skill and plugin tooling

Most of the work went into OpenCode skill tooling. opencode-skill-management built the skill_management plugin with list, inspect, disable and enable actions, moved plans into .openchamber/plans, normalized line endings to LF, and shipped 0.1.0-rc.0, 0.1.0-rc.1, 0.2.0, 1.0.0, 1.1.0 and 1.2.0, the last turning all four actions into a single validated JSON result. opencode-go-model-picker added shared JSON and proxy helpers, fuller agent discovery with skipped built-ins reported, atomic snapshot writes, version-drift checks and a priced-accounting reference, releasing 1.4.0, 2.0.0, 3.0.0 and 3.0.1. opencode-agent-sandbox started from an initial commit and grew a knowledge base covering OpenCode V2 distribution, authentication, Windows path issues and remote branch deletion.

Translation, pixel art and research

sopen-translate was initialized and grew an MV3 extension skeleton, a provider protocol layer with presets and a glossary pipeline, bilingual page rendering with chunk splitting and a circuit breaker, page-state resets between runs, JSDoc type checking and a DOM smoke test; selection translation was later dropped. pixel-logo-toolkit added automatic text wrapping with overflow protection, bilingual CLI output, an English-first README with a Chinese version, a 40-image command gallery, a Korean font fix and README corrections, releasing 0.2.0 and 0.3.0. meld-deepresearch restructured both READMEs to the Standard Readme spec, added a thin meld.py CLI, lightened the skill, made the academic degrade test dependency-aware and released v0.3.1 and v0.4.0.
