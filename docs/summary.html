Own projects

Most of the coding effort went into sogeisetsu/asset-inventory, which moved through a long chain of releases from v1.3.0 to v1.15.0. The work covered an English-first rewrite with paired Chinese docs, a seven-language documentation site, rendered bilingual sample pages, a new broken-state marker for registered but uninvokable assets, security guards for discovery, a release-prep script with a docs-parity gate, and a registry-first host-command scan. Documentation checks were automated through a PR-triggered workflow, and the SKILL.md text was trimmed repeatedly.

A second cluster of work went into sogeisetsu/meld-deepresearch, which grew from v0.1.0 to v0.4.0. The releases added rule-based handling for unavailable sources, a validator that explains failures, a family of three cooperating skills, a thin meld.py CLI wrapping the gate scripts, a bilingual Pages landing page with light and dark themes, and validation scripts with CI.

The OpenCode skill tooling also moved forward. opencode-go-model-picker shipped v1.0.0 through v1.4.0 with plan-aware model allocation, a three-part output, agent discovery scripts and proxy-aware network helpers. opencode-skill-management reached v0.2.0 with a plugin that lists, inspects, disables and enables skills through a config permission rule, and opencode-agent-sandbox accumulated knowledge notes in the initial commit series.
