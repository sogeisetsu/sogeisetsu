OpenCode skill tooling

Most of the work went into three OpenCode skills. opencode-skill-management was documented and released three times: v1.0.0 froze the list/inspect/disable/enable surface, v1.1.0 switched all four actions to a single JSON object with a declared output schema, and v1.2.0 fixed the diverged-agent count and frontmatter boolean normalization. The same repo also gained an Astro + Starlight bilingual docs site deployed through GitHub Actions, plus landing-page and mobile fixes.

opencode-go-model-picker moved from priced accounting and Console calibration in 2.0.0 to a much smaller 3.0.0 layout, then 3.0.1 enforced the candidate model menu, per-source chains and a comparing check. Later commits added the format-side self-check list, documented where each money source may print, and stopped the calibrate step from restamping an old bias with today's date.

opencode-agent-sandbox was the busiest repository by commit count, almost entirely knowledge-base documentation: the OMO slim skill table, the openchamber-storage category, VS Code harness notes, and SenseNova image-skill notes with a Windows-without-WSL2 correction. One pull request was opened there.

Translation, pixel art and reports

sopen-translate built an MV3 extension skeleton, then added a provider protocol layer with presets, model lists and a glossary pipeline, bilingual page rendering with chunk splitting, a circuit breaker and progress, and dropped selection translation in favour of page translation only. It also gained JSDoc checkJs type checking and DOM smoke tests.

pixel-logo-toolkit shipped v0.2.0 and v0.3.0: automatic text wrapping with overflow protection, a bilingual CLI, an English-first README with a Chinese version, a 40-image command gallery, and a Korean font fix because Ark Pixel's ko build lacks Hangul. dsh-ecosystem-report got a single-button theme menu, mobile viewport fixes at 375 and 414, visual refinements and three merged plugin entries. dsh-openchamber-plugins added a hidden-files toggle, an /init skill and a zh-doc-sync skill, and archived ported skills. myBlog received two documentation commits with screenshots.
