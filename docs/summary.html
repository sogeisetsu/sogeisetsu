Own repositories

Most of the window's effort went into sogeisetsu/asset-inventory, which was moved through a long run of releases from v1.3.0 to v1.15.0 plus several patches. The early releases made the repository English-first, added paired Chinese docs and a seven-language fixed-string glossary, and split long-form documentation out of the READMEs. Later releases turned documentation rules into automated checks: a PR-triggered docs check, a version-consistency check, a language-claim check that fails when an advertised language has no glossary block, and a reference-integrity check. A release-prep script and a docs-parity gate were added afterwards.

Asset-inventory also received substantive inventory fixes. MCP enumeration previously stopped after one server and was corrected to read every key and assert the row count; update.ps1 nested-directory handling was repaired; host-command scanning was rewritten to enumerate the app bundle's own registries first. A fifth state marker, broken, was introduced for assets registered in config but not invokable, and security guards were added so that scanned text is treated as evidence rather than instructions. Install guidance moved to git clone and later to a one-line skills.sh install.

sogeisetsu/sogeisetsu was reworked substantially: profile copy switched to English, a 30-day activity card with a daily automated update workflow was added, the daily report moved to rolling two-hour updates with a date input for manual runs, and CI was upgraded off the deprecated Node 20 runtime. Several fixes made the reported statistics and their breakdowns stay consistent.

sogeisetsu/meld-deepresearch grew from v0.1.0 to v0.4.0. The releases added a bilingual GitHub Pages landing page, a Chinese README with language switching, validation scripts and CI, a first-class observations evidence type, an explicit rule for sources behind paywalls or bot walls, and a thin meld.py CLI wrapping the gates. v0.3.0 split the single skill into three cooperating skills, including a spreadsheet data-analysis skill adapted from SenseNova-Skills.
