OpenCode tooling

sogeisetsu/opencode-agent-sandbox was the busiest repository by commit count, with 81 own commits and no automated ones. Nearly all of it was knowledge-base writing: a full table of the 11 skills shipped with OMO slim, the three behaviour-constraint skills added in OMO slim v3.0.5, a new openchamber-storage category covering whether pasted images go to files or the database and the delete-without-shrink plus VACUUM flow, and a planning-capability table. VS Code notes were extended with extensions, keybindings and Copilot/BYOK material, two claims about opening VS Code were verified, and the SenseNova quick reference gained an image skill entry plus a correction that Windows does not need WSL2. One pull request was opened here.

sogeisetsu/opencode-skill-management produced 53 own commits and three releases. The repository gained an Astro plus Starlight bilingual documentation site (English at root, Chinese under /zh-cn) deployed through GitHub Actions, with follow-up fixes aligning the landing page and mobile layout, fixing theme persistence and example rendering, and separating selected from hovered menu states. Release policy and a Chinese release note were documented, and the 1.0.0 release result (npm latest, CI on both platforms, checksums) was recorded. v1.0.0 shipped on 2026-10-23, followed by v1.1.0 and v1.2.0 on 2026-10-29 and 2026-10-31; 1.1.0 moved all four actions to a single JSON object with a declared output schema, and 1.2.0 fixed the diverged-skill summary that counted hidden internal agents and normalised frontmatter booleans.

sogeisetsu/opencode-go-model-picker had 20 own commits and three releases. Development covered priced accounting, Console calibration and an output v2 layout, documentation of which money source each basis may print, placeholder-based examples, a self-check list for the format side, and moving test prompts into tests/. The calibrate command was fixed so it never restamps an old bias with today's date. v2.0.0 arrived on 2026-10-29 with the priced-accounting formula and Console MCP probing, v3.0.0 on 2026-10-31 cut the model-facing text from roughly 27,400 to about 2,200 tokens and collapsed nine runtime scripts into one go.mjs entry point, and v3.0.1 on 2026-11-02 enforced the candidate model menu, per-source chains and a comparing check gate.

Translation, graphics and reports

sogeisetsu/sopen-translate was initialised and built out over 56 own commits: an MV3 skeleton, a provider protocol layer with presets, model lists and a glossary pipeline, bilingual page rendering with chunk splitting, a circuit breaker and progress reporting, then a refactor dropping selection translation in favour of page translation only. Fixes reset page state between runs, added a two-round restore DOM smoke test, required-field validation and JSDoc-based checkJs type checking.

sogeisetsu/pixel-logo-toolkit used 29 own commits and shipped two releases. Text now wraps automatically with CJK per-character breaking and hard-splitting of overlong Latin words, overflow protection steps font sizes down to a 9px floor, and the CLI became bilingual with an English-default README plus a Chinese version. Korean switched to the Galmuri font because Ark Pixel's ko build lacks Hangul, and a 40-image command gallery was added. v0.2.0 was the first tagged release on 2026-11-02 and v0.3.0 followed on 2026-11-03 with wrapping and overflow work.
