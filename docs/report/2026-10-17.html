  • v1.4.0v1.4.0·Oct 17, 20262026年10月17日
    sogeisetsu/opencode-go-model-picker

    What's new

    • Our scripts now share two small helpers. One reads JSON that carries a BOM and writes it atomically (temp file, then rename over the target). The other re-runs a script with a proxy when your system has one. So all four network scripts respect a configured proxy, and a Node runtime that can't use one says so on stderr instead of looking like a network outage.
    • Agent discovery is more complete. scripts/discover-agents.mjs now reports mode, hidden, traits (worked out from the agent's description, name and mode, with known roles taking priority) and provenance.fetchedAt. Built-in names it skips show up under skippedBuiltins instead of disappearing, and the workflow now asks you about any entry that might be one of your own agents.
    • New flags: --include-builtin-names, --builtin and --extra-builtin for agent discovery, and --rebuild for the snapshot refresh.

    Changed

    • Refreshes now write the snapshot safely. If the existing snapshot can't be parsed, the script stops with a clear message and leaves your file alone — including your remembered mode and cached scores. It used to quietly start from an empty cache. Use refresh-snapshot.mjs --rebuild to discard it on purpose.
    • The catalog fetcher and the snapshot summary use the shared helpers too, so what one script writes is what the next one expects.
