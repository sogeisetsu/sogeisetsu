  > ## English
  > 
  > ### What this release is
  > 
  > - \*\*Core capability:\*\* the new \`Lead\` Agent preset lets the main agent pass \`agent\_preset\` to \`subagent\` and give every spawned child a different preset (\`worker\` / \`reader\` / \`cordis\`); omitting the parameter inherits the parent's preset.
  > - Two teammate presets ship alongside it: \*\*Worker\*\* (writable: files, search, shell, subagent controls) and \*\*Reader\*\* (read-only: read and search only, with no write or shell tool).
  > - The plugin name is English in every UI language (\`Subagent preset select\`), and the description was rewritten to lead with the capability — Lead lets each subagent run a different preset — instead of “adds three presets”.
  > - Preset roster descriptions are bilingual single-line strings (DSH does not localize user-authored preset metadata; see upstream Discussion #3610).
  > - Added \`CONTRIBUTING.md\` and a Chinese \`CHANGELOG.md\`.
  > 
  > ### Install
  > 
  > 1. Download \`dsh-subagent-preset-select-1.2.0.tgz\` from this release.
  > 2. Either:
  > - CLI: \`dsh plugin --profile &lt;profile&gt; add &lt;downloads&gt;/dsh-subagent-preset-select-1.2.0.tgz\`
  > - Desktop: Plugins → Add plugin, then the absolute path of the \`.tgz\`.
  > 3. Pick \`Lead\` as the new-session default in Settings → Agent Preset (or select it for a single session).
  > 
  > &gt; The \`.zip\` holds the same files for browsing; install DSH from the \`.tgz\`.
  > 
  > ### Requirements
  > 
  > - DSH \`0.2.2-rc.5\` Desktop (\`engines.dsh\`: \`&gt;=0.2.2-rc.5 &lt;0.3.0\`).
  > - Node.js &gt;= 22.15 only for the local validation script.
  > 
  > ### Rollback
  > 
  > - Switch the new-session default back to \`Standard\` in Settings → Agent Preset, or disable/uninstall the bundle in Plugins.
  > - The shipped \`standard\` preset is never overwritten.
  > 
  > ### Verification
  > 
  > - \`SHA256SUMS.txt\` is attached; verify with \`sha256sum -c SHA256SUMS.txt\` (or \`Get-FileHash\` on Windows).
