    v1.3.0

    中文

    这个版本在做什么
    • worker / reader 队友预设现在挂载 skill-filesystem + tool-skill：子智能体也能使用项目技能（<project>/.dsh/skills、<project>/.agents/skills）与用户技能（~/.dsh/skills、~/.agents/skills）；随 DSH 分发的 dsh-doc 仍只给 lead。
    • 重画插件图标：透明背景、36×36；父节点 → 两个形状与颜色都不同的子节点（品牌蓝实心圆角方 + 琥珀色菱形），表达「同一个父智能体可以给不同子智能体指定不同 preset」。
    • Lead 的 preset 卡片简介改为「相当于标准模式，另外可以给派生的每个子智能体指定不同的预设」；Plugins 页该行简介同步。
    • README（中英）重构：新增 Usage 章节（把新会话切到 Lead、用 agent_preset 派活的示例、团队协作、如何选 preset）与 License 章节；安装方式补上 npm，限制说明重写。
    • 安装包内部结构：每个 preset 的声明放在自己的 unit 目录（lead/preset.patch.yml、worker/preset.patch.yml、reader/preset.patch.yml），根 cordis.patch.yml 移除。
    • npm 发布：dsh-subagent-preset-select 现在可从 npm 安装；发布使用 Trusted Publishing（OIDC），不再依赖长期 token。
