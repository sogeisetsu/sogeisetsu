## Releases

- `v0.2.0` [v0.2.0 — First release: bilingual CLI, English-first docs](<https://github.com/sogeisetsu/pixel-logo-toolkit/releases/tag/v0.2.0>) — `sogeisetsu/pixel-logo-toolkit`
  > \*\*pixellogo 0.2.0\*\* is the first tagged release: a command line tool that turns a title, a few subtitle lines and a footnote into real 8-bit / retro-terminal pixel art — PNG and SVG from the same geometry, five canvases, ten palettes, and mixed Latin / Chinese / Japanese / Korean text without missing glyphs.
  > 
  > ## Highlights
  > 
  > - \*\*Real pixels, not a filter.\*\* Text is rasterized into a binary mask and merged per row into integer-coordinate rectangles. Every edge stays a whole block at any zoom: no anti-aliasing, no gradients, no feathering.
  > - \*\*One geometry, two formats.\*\* PNG and SVG are produced from the same \`Scene\`, so they match pixel for pixel. The SVG is self-contained and needs no font files.
  > - \*\*Five canvases.\*\* \`poster\` 1080×1440, \`card\` 1440×1080, \`banner\` 1280×640, \`slide\` 1920×1080, \`square\` 1080×1080, each with its own layout strategy.
  > - \*\*Ten palettes.\*\* From retro terminal to paper journal; every preset passes a WCAG contrast check (\`--list presets\` prints the ratio).
  > - \*\*CJK-ready.\*\* A Chinese pixel font ships in the box, so mixed Latin/Chinese lines keep one stroke weight; Traditional Chinese, Japanese and Korean download on demand.
  > - \*\*Bilingual CLI.\*\* Help page, option tables, font status, warnings and errors in English or Simplified Chinese — automatic from the terminal locale, or forced with \`--ui-lang\`.
  > - \*\*No browser dependency.\*\* Pure Python and Pillow rasterization; runs on servers and in CI.
  > - \*\*Reusable configuration.\*\* JSONC files with comments and trailing commas, dot-path overrides, batch mode, and a \`--dry-run\` snapshot of the merged result.
  > 
  > ## New in 0.2.0
  > 
  > ### Bilingual command line
  > 
  > All terminal output now exists in English and Simplified Chinese: the help page, \`--list modes|presets|fonts\`, \`fonts\` status, warnings, and every error message (including argparse's own argument errors).
  > 
  > - Automatic: \`LC\_ALL\` → \`LC\_MESSAGES\` → \`LANG\` → \`LANGUAGE\` → Windows UI language → English. \`C\` / \`POSIX\` count as English.
  > - Explicit: \`--ui-lang auto|en|zh\` for a single run, or \`PIXELLOGO\_UI\_LANG\` as a persistent default. Precedence is flag &gt; environment &gt; locale.
  > - \`--ui-lang\` (CLI wording) is independent of \`--lang\` (glyph variant used for the image): \`--ui-lang en --lang ja\` gives an English interface with Japanese glyphs.

  > ## Quick start
  > 
  > \`\`\`bash
  > # One cover image, both formats, into out/
  > pixellogo -t "REA" -s "REVERSE ENGINEER" -d "One CLI for agents"
  > 
  > # A 16:9 slide cover in the cyber palette with a grid texture
  > pixellogo -t "PIXEL" -m slide -p cyber --bg-pattern grid
  > 
  > # Inspect what is available
  > pixellogo --list modes
  > pixellogo --list presets
  > pixellogo fonts
  > \`\`\`
  > 
  > Running \`pixellogo\` with no arguments prints the help page; \`--help\`, \`-h\` and \`pixellogo help\` are equivalent.
  > 
  > ## Command line at a glance
  > 
  > | Flag | Effect |
  > | --- | --- |
  > | \`-t, --title\` | Main title (required) |
  > | \`-s, --subtitle\` / \`-d, --desc\` | Subtitle and footnote lines, one flag per line |
  > | \`-m, --mode\` | \`poster\` / \`card\` / \`banner\` / \`slide\` / \`square\` |
  > | \`-p, --preset\` | One of the ten palettes |
  > | \`--bg\` \`--fg\` \`--primary\` \`--accent\` \`--shadow-color\` | Single-color overrides |
  > | \`-f, --format\` | \`png\` / \`svg\` / \`both\` (default \`both\`) |
  > | \`-o, --out\` | Output file or directory |
  > | \`-c, --config\` / \`--set\` | JSONC config and dot-path overrides |
  > | \`--ui-lang\` | CLI output language: \`auto\` / \`en\` / \`zh\` |
  > | \`--lang\` | Glyph variant: \`zh-hans\` / \`zh-hant\` / \`ja\` / \`ko\` |
  > | \`--json\` / \`--dry-run\` / \`--open\` | Machine-readable output / merged config / open the result |
  > 
  > Exit codes: \`0\` success, \`2\` invalid arguments or configuration.
  > 
  > ## Python API
  > 
  > \`\`\`python
  > from pixellogo import render, make\_image, make\_scene, to\_svg\_text
  > 
  > paths = render(title="REA", mode="banner", preset="cyber", format="png", out="out/")
  > image = make\_image(title="REA", mode="square", scale=1)
  > scene = make\_scene(title="REA", mode="poster")
  > svg = to\_svg\_text(title="REA", mode="slide")
  > \`\`\`
  > 
  > Keyword names match the JSONC config keys exactly, so anything valid in a config file is valid here.
