    What's new in v0.4.0

    This release spans everything since v0.3.0, including the v0.3.1 patch (skill descriptions now carry the search terms people actually type). The headline changes make the skill smaller to read, safer to re-run, and harder to misuse.

    One command in, one command out: meld.py

    The gates are still the same scripts, but you no longer need to remember their paths or flags. skills/meld-deepresearch/scripts/meld.py wraps all six of them behind one --outdir:

    • meld.py prepare merges the per-axis files and runs gate ① (it picks up .work/plan.json automatically on a normal run)
    • meld.py render writes both report files plus citations.json in one shot
    • meld.py review [--clean] picks the right file for you — structural pass or delivery gate
    • meld.py verify runs the whole chain and stops at the first failure, naming the stage that failed

    Every command stays independently runnable, and references/protocol.md §9 is now the single place that lists the gate commands (raw forms kept alongside as equivalents).

    Fix the common failures automatically

    content_review.py --fix repairs the two mechanical mistakes it used to only report: a labelled counter-evidence callout (**最强反证：** / **Strongest counter-evidence:**) is unwrapped back into the paragraph it belongs to, and generic container headings (## Findings, ## 分析, …) are demote…
