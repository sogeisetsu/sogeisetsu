  • v0.2.0v0.2.0·Oct 3, 20262026年10月3日
    sogeisetsu/meld-deepresearch

    What's new in 0.2.0

    This release hardens the research protocol and ships the evaluation work that
    came out of comparing this skill against other deep-research skills.

    Sources you cannot open are now handled by rule

    The strongest primary sources are often behind a paywall or a bot wall. Until
    now, the right response — record the failure, note the gap, and never pass a
    snippet off as the original — was implied but not written down. It now is: a
    blocked page is logged as an observation with its HTTP status, the gap goes into
    the report as an availability caveat, and a claim whose only support is an
    unreachable source is labelled unknown instead of quietly softened.

    The validator tells you how to fix a failure

    A failed run used to get a code and a location. It now also gets one
    "smallest safe fix" hint per actionable error — whether to re-key a claim, add a
    second independent origin, or drop an unreachable reference — so a single
    allowed correction is spent on the right change.

    A new warning for same-publisher "independence"

    If an interpretive claim rests on several URLs that all belong to one publisher
    (a wire story re-published across one outlet), the validator now warns with
    W_SAME_PUBLISHER. It is a hint, not a failure: the check is a heuristic and
    never blocks delivery.

    sogeisetsu/opencode-go-model-picker

    Two versions of work are rolled up here (v1.2.0 and v1.3.0).

    Better agent discovery and chain safety

    • New scripts/discover-agents.mjs: a read-only, zero-dependency CLI that lists your

    custom agents (slim and native sources) and flags risky fallback chains — duplicate
    model ids, chains outside 2–4 entries, non-Go fallback ids not confirmed in the
    local registry, and vision lanes whose model is not marked vision-verified. It
    prints compact JSON instead of making you read config files by hand.

    • New scripts/snapshot-summary.mjs: a compact digest of the cached model snapshot

    (~97% shorter than the raw file), with --ids, --trait, and --json.

    Clearer recommendations

    • The recommendation table now includes a role overview column: a one-line,

    plain-language description of what each agent does, so a suggestion can be judged
    without knowing the role by heart.

    • A dominance check now closes model allocation: if another model is no worse on

    price, throughput and the trait-relevant capability (and strictly better on at
    least one), the dominated model is replaced — or must be justified in the "why"
    column (for example, a cross-provider fallback).
